# 98Setup

Программа для создания собственных установщиков в стиле Windows 98.

## Описание

98Setup позволяет разработчикам и энтузиастам создавать установщики для своих приложений, оформленные в классическом стиле операционной системы Windows 98.

## Возможности

- Создание установщиков с интерфейсом в стиле Windows 98
- Классические окна, кнопки и диалоги той эпохи
- Настройка шагов установки и отображаемого контента
- Поддержка пользовательских ресурсов и файлов
- Простая конфигурация без необходимости глубокого программирования

## Установка

Перекиньте папку 98Setup в любое место либо запустите прямо из архива. Для запуска требуется .NET 8 версии.

## Лицензия

Лицензии на продукт нету. Продукт имеет open-source исходник, программу изменять разрешаеться, продавать за деньги категорически запрещено (Продукт создан для бесплатного доступа)
